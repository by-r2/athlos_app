# Kleos

**Profile → Kleos** focuses on measurable outcomes from training logs.

## Order of information

1. **Purpose copy** — short hero banner: what Kleos reflects.
2. **Resumo** — KPI tiles: total finished sessions, estimated PR count, optional muscle-group PR coverage — **no** duplicate of weekly rhythm (that belongs in Consistency).
3. **Consistência** — streaks + current week tally / target (Olympus-equivalent semantics).
4. **Última evolução** *(only if comparable)* — two finished runs of the same workout template.
5. **Força por grupo muscular** — horizontal **chips** to pick group; best estimated 1RM and lift row below (tap → exercise).
